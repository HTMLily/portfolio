# Jared Samuel D. Navarro — Portfolio

A responsive single-page portfolio built with plain HTML, CSS, and JavaScript.

## Preview locally
Open `index.html` in a browser, or use VS Code with the Live Preview extension.

## Personalize before publishing
- Replace the sample project cards in the Projects section with your real projects and images.
- Your uploaded resume is already included at `assets/resume.pdf`. Replace it there if you update your resume.
- Review the content and contact details before publishing. Your resume contains personal information that will be publicly accessible if you publish the site.

## Publish with GitHub Pages
1. Create a public GitHub repository named `portfolio`.
2. Upload the contents of this folder (including `index.html` and `assets/`).
3. Open repository Settings → Pages.
4. Choose “Deploy from a branch”, select `main` and `/(root)`, then Save.
5. Wait for the published HTTPS link in Settings → Pages.

This site uses no framework or build step.
